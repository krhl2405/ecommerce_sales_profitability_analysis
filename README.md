# E-Commerce Sales & Profitability Analysis

## Business Problem

The objective of this project is to analyze e-commerce sales and profitability
data to identify key revenue drivers, profitable categories and regions,
customer performance, and overall business trends.

## Objectives

- Analyze sales and profit trends over time
- Identify top-performing categories and sub-categories
- Analyze regional profitability
- Evaluate customer segments
- Identify top customers by revenue
- Analyze sales-to-profit performance
- Develop an interactive business dashboard

## Tools Used

- Python – Data cleaning and preparation
- SQL Server – Business analysis and KPI calculations
- Power BI – Dashboard development and visualization

## Project Workflow

1. Data Cleaning & Preparation using Python
2. Business Analysis using SQL Server
3. KPI Development and Dashboard Creation using Power BI
4. Business Insights and Recommendations

## Key Analysis

The project analyzes:

- Monthly and yearly sales
- Monthly and yearly profit
- Category and sub-category performance
- Regional profitability
- Customer segment performance
- Top customers by revenue
- Sales-to-profit relationship

## Dashboard

The Power BI dashboard provides an interactive view of:

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Category
- Profit by Region
- Yearly Sales and Profit Trends
- Top 10 Customers

## Deliverables

- Python Jupyter Notebook
- SQL Analysis Queries
- Power BI Dashboard
- Business Report
- Project Presentation

## Conclusion

The analysis provides a consolidated view of sales and profitability
performance and highlights important areas that can support business
decision-making.
